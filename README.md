# 🍺 Brewery Shop Finder  

Find breweries in any city with ease! This Node.js and Express-based web application helps users search for breweries using the **OpenBreweryDB API** and displays results in a well-structured card layout.  

## 🚀 Features  
- Search for breweries in any city  
- Displays name, location, coordinates, and website (if available)  
- Interactive map link to view brewery location  
- Responsive UI built with **EJS** and **CSS**  

## 🛠️ Technologies Used  
- **Node.js** & **Express.js** – Backend server  
- **EJS** – Template engine for dynamic rendering  
- **Axios** – Fetching data from the OpenBreweryDB API  
- **CSS** – Styling the UI  
- **Body-Parser** – Handling form submissions  

## 📦 Installation  
1. Clone the repository:  
   ```bash
   git clone https://github.com/your-username/brewery-shop-finder.git
   cd brewery-shop-finder
   ```
2. Install dependencies:  
   ```bash
   npm install
   ```
3. Start the server:  
   ```bash
   npm start
   ```
4. Open in browser:  
   ```
   http://localhost:3000
   ```

## 🔍 How It Works  
1. Enter a city name in the search bar.  
2. Click "Search" to fetch brewery details.  
3. View brewery details in a card layout.  
4. Click "Visit Website" (if available) or "Location" to view on Google Maps.
